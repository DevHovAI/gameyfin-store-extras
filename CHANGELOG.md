# Changelog

## 1.2.0

- New: player counts as badges, from PCGamingWiki. For every mode the wiki lists as available, the description's badge
  line gets a badge such as `Local 4 players`, `LAN 100 players` or `Online 4 players, Co-op`. Counts can be
  numbers or ranges (`2-4`); when the wiki has the mode but no count, the badge shows the mode only
  (`Online multiplayer`). Co-op and Versus are added where the wiki names them.
- The wiki page is found through the Steam app id (GOG id for GOG-only titles) and the id in the page's infobox is
  checked, with a title search as fallback. Results are cached (24 h, failures 1 h), requests are at least one second
  apart, and any PCGamingWiki problem simply means no extra badges: the rest of the metadata is unaffected.
- The user agent now names the plugin and its repository.

## 1.1.0

- Fix: 1.0.1 was published without `META-INF/extensions.idx`. Gameyfin then showed the plugin as running and valid
  but never called it, so it contributed nothing. The index was generated by KSP, whose output a cached build
  dropped. It is now a checked-in resource, the build fails if the JAR lacks it, and a test checks it.
- New: `description`. Markdown with a line of shields.io badges (Steam score and label, GOG score, Metacritic,
  Steam Deck Verified, game modes) on top, followed by the store text converted from HTML. Steam first, GOG for
  titles Steam does not sell.
- New: `features`, mapped from Steam categories (GOG's feature list as fallback).
- The one hour pause after Steam's `appreviews` refusal is explicitly limited to that endpoint (covered by a test).
- Store Extras should now be the highest priority provider, so that it also wins description and features.

## 1.0.1

- Fix: search results of Store Extras were never merged with those of Steam, IGDB and the other providers, so the
  provider's ID was not stored with the game and its ratings, banners and trailers were never refreshed. Results now
  carry the release date (Steam, GOG as fallback), which Gameyfin uses together with the title to group results.
  The date is start of day UTC, the same instant the official Steam Metadata plugin reports.

## 1.0.0

- Metadata provider "Store Extras": Steam user rating, Metacritic score, banner images and trailers,
  with GOG as fallback source.
